# One Page Resume

> **一页纸的个人官网，也是一个能直接改的简历。**
>
> 改简历真正的成本从来不是「写」，而是「改」——改完要重新排版、重新导出、重新发一版，还得记住哪一版才是最终版。
>
> One Page Resume 把整件事压成一次点击：**你看到的，就是最终版；你改的，就是磁盘上那个文件。**

一个**零依赖、零构建、单 HTML 文件**的中文简历模板。没有 npm、没有打包器、没有账号、没有云端——双击打开就能渲染，在页面上直接点字就改，退出编辑态自动写回 `.html` 文件本身。需要投递时，浏览器打印即出 A4 PDF，或者用配套脚本导出排版规整的 Word。

**三个文件，就是全部：**

| 文件 | 作用 |
| --- | --- |
| `resume-template.html` | 模板本体：排版、四套主题、编辑系统、楼层管理、打印样式、PDF 精简版式全在这一个文件里 |
| `resume_sync.py` | 可选的本地同步服务：托管目录 + 接收页面回写（原子写盘、自动备份） |
| `export_resume_docx.py` | 把渲染后的页面导出为 A4 版式的 `.docx` |

---

## 为什么是「单文件」

- **打开即最终形态**：不是 Markdown → 编译 → 预览的中间态，网页本身就是成品。发给别人、挂到个人域名、塞进邮件附件，都是同一份东西。
- **编辑不留副本**：内容存在页面里，退出编辑态直接写回原文件（或导出一份自带全部内容的独立副本）。不存在「改了三版不知道哪版是新的」。
- **图片内嵌**：头像、二维码、列表插图都以 base64 内联进 HTML，换电脑、发给别人、断网打开，所见完全一致。
- **打印是设计的一部分**：专门写了 A4 精简版式、分页控制、背景图形兜底，不是「网页硬塞进纸里」。

---

## 能做什么

### 编辑

- **点字即改**：`Esc` 或底部「编辑」按钮切换编辑态，正文所有字段就地编辑；`Esc` 再按一次退出并保存。
- **撤销 / 恢复**：最近 10 步历史，`⌘/Ctrl + Z` 撤销，`+ Shift` 恢复。
- **条目可增删**：数据条、优势卡、AI 历程节点、整段经历、经历内小节块、要点列表项、标签，都能一键新增 / 删除（带条数上限保护）。
- **插图**：列表里可插入图片条目（≤1000×1000，展示宽约 6 个汉字），图片下方带一个 ≤5 字的可编辑名称。
- **头像**：按证件照通用规范上传，竖版 5:7（一寸 295×413 / 二寸 413×579），自动裁剪压缩。
- **二维码位**：「在线体验」行旁两个二维码槽，编辑态点击上传，底部可写 4 字名称，可单独删除。
- **外链自动跟随文案**：改链接文字，`href` 同步更新，不会出现「文案改了、点击还是旧地址」。
- **格式刷**：选中一段点「复制格式」，再选中另一段点「粘贴格式」，统一字号/强调样式。

### 排版与外观

- **四套主题**：鎏金（默认 · 高端纸感）、曜石（暗夜金调）、青瓷（东方雅致）、盘面（交易终端个性风）。
- **强调色**：鎏金 / 香槟 / 青瓷 / 黛蓝 / 印泥红 / 琥珀，外加「跟随主题」。
- **字号档位**：12–22px 基准字号，整页按比例缩放。
- **楼层可插拔**：头部、数据条、优势、AI 历程、经历、教育与其他、独立项目、结尾联系共 8 个楼层——点击眼睛显隐，按住拖动排序，一键恢复默认顺序 / 全部显示；左侧点线导航与楼层顺序自动联动，隐藏的楼层不进导航。
- **旧草稿自动迁移**：模板结构升级后，浏览器里存的老草稿会在加载时被自动迁移，不会白改。

### 输出

- **PDF**：底部「导出 PDF」自动切到精简版式 + 浅色纸面，导出后还原；已处理去页眉页脚、A4 断点、分页与背景图形兜底。
- **Word**：`export_resume_docx.py` 渲染 DOM 后按结构提取文本，生成 A4、带金色分隔线的 docx。
- **保存副本**：底部「保存副本」把含当前全部内容的独立文件写到项目目录（文件名自动带日期时间），未启服务时改为浏览器下载。副本带独立的 `data-share-id`，有自己的存储位，与母本互不串内容。

## 快速开始

### 1. 编辑

编辑功能本身**不需要任何依赖**。把改动**写回文件**有三条路，页面会自动选：

1. **直连原文件（推荐，零依赖）** —— 用 Chrome / Edge 打开，第一次点「编辑」时浏览器让你选一次本文件，之后每次「完成 / 退出编辑态」直接写回磁盘，不需要任何服务。授权记在浏览器里（IndexedDB），下次打开仍然有效。
2. **本地同步服务** —— 见下。服务开着时**不会**弹文件选择框，页面静默走服务回写。
3. **下载副本** —— 两条都不通（Safari / Firefox 且没起服务）时自动降级，内容不会丢。

> 浏览器出于安全限制，无法在打开 HTML 时自动启动本机程序，所以「完全无感」最多做到「授权一次 → 之后静默」。

底部有个**状态胶囊**实时显示当前走哪条路；点它可以手动重新连接原文件。

#### 本地同步服务（可选）

```bash
python3 resume_sync.py                 # 默认 8765 端口，托管本目录
python3 resume_sync.py --port 9000     # 换端口
python3 resume_sync.py --dir /path     # 托管别的目录
```

然后打开终端里列出的地址（默认 <http://127.0.0.1:8765/resume-template.html>），直接点文字改。
点「完成 / 退出编辑态」时页面把完整 HTML POST 回 `/__save`，服务端**原子写回原文件**，写前留一份备份到 `.resume-backups/`（同名最多保留 10 份）。

服务已放开 CORS，所以**用 `file://` 双击打开页面、服务在后台跑着**也能自动回写，不一定要从服务地址打开。

| 接口 | 说明 |
| --- | --- |
| `GET /__ping` | 探活，页面用它判断服务是否在线 |
| `GET /__files` | 列出目录里的 `.html` |
| `POST /__save` | 回写同名的**已存在** `.html`（写前备份） |
| `POST /__save_as` | 另存新副本，同名自动 `-2/-3` 避让，绝不覆盖 |

停止服务：`pkill -f "resume_sync.py"`。

### 2. 导出 Word

只有这个脚本需要依赖：`playwright>=1.44`、`python-docx>=1.1.0`。

```bash
pip install "playwright>=1.44" "python-docx>=1.1.0"
playwright install chromium            # 或设 CHROME_PATH 指向已有 Chromium
python3 export_resume_docx.py                        # 默认 resume-template.html → resume-template.docx
python3 export_resume_docx.py 源文件.html 输出.docx   # 指定文件名
```

脚本用 Playwright 渲染页面后按 DOM 提取文本（自动跳过隐藏楼层、编辑态 UI、图标），生成 A4、带金色分隔线的 docx，并在终端打印识别到的楼层、数据条与经历段数。

### 3. 导出 PDF

直接用浏览器打印（`Ctrl/Cmd + P`），或点底部「导出 PDF」按钮（自动切精简版式）。模板带专门的打印样式与「PDF 版式」开关，屏幕上也能预览精简效果。

## 安全提醒

`resume_sync.py` **只监听 `127.0.0.1`**，且带有写文件接口。请不要把它部署到公网或改成 `0.0.0.0` 暴露出去。

写入限制（本地防护）：只允许写托管目录内**已存在**的 `.html`、文件名不得含路径分隔符或 `..`、单次请求体上限 20MB、写盘为临时文件 + `os.replace` 原子替换。

## 已知注意事项

- **无痕窗口 / 换浏览器内容不同**：这是 localStorage 草稿有无的问题。普通窗口改过的内容不会出现在无痕窗口，固化内容要靠回写原文件或「保存副本」。
- **改了文件没生效**：先硬刷新（`Cmd/Ctrl + Shift + R`）。页面加载时会套用本地草稿，旧页面可能把旧代码写回文件。
- **字体**：docx 导出写死「微软雅黑 / Microsoft YaHei」（脚本顶部 `FONT` 常量可改）。Windows 正常；macOS / Linux 上生成的文档在缺该字体的机器打开会回退字体。
- **在线字体**：HTML 从 Google Fonts 加载 Noto Serif SC / Inter / JetBrains Mono。离线或访问不畅时降级回系统字体（不影响功能）；介意访客 IP 泄露给 Google 的话，可改为本地字体或删除 `<link>`。
- **备份目录**：`.resume-backups/` 由 `resume_sync.py` 自动创建，本仓库已用白名单式 `.gitignore` 排除——目录里放含真实手机/邮箱的个人简历也不会被误提交。
